# Bayesian Statistics (bayesian-statistics-ai999x)

[![tests](https://github.com/AI999X/bayesian-statistics-ai999x/actions/workflows/ci.yml/badge.svg)](https://github.com/AI999X/bayesian-statistics-ai999x/actions/workflows/ci.yml) [![PyPI](https://img.shields.io/pypi/v/bayesian-statistics-ai999x)](https://pypi.org/project/bayesian-statistics-ai999x/) [![Hugging Face](https://img.shields.io/badge/%F0%9F%A4%97-Hugging%20Face-yellow)](https://huggingface.co/AI999X/bayesian-statistics-ai999x)

Bayesian Statistics covers Bayes' theorem, conjugate priors and posteriors, credible intervals, Bayes factors, Monte Carlo estimation, uncertainty propagation, sensitivity analysis and decision analysis: 78 calculations in 12 topics, each with its formula, its steps and its units, and a plain reason instead of a number when an input is missing or out of range. One compiled engine, four ways to use it: the desktop app, the command line, the browser and Python. Everything runs on your own computer, offline.

[![The Bayesian Statistics desktop app: Positive and negative predictive values of a test, with its worked example and live scene](https://www.ai999x.com/?ax_shot=bayesian-statistics-ai999x/hero.webp)](https://www.ai999x.com/models/bayesian-statistics-ai999x/)

## Ask in words: 15 examples

Each question below was asked on this release; the comment under it is the line it printed.

```python
import bayesian_statistics_ai999x as bayesian_statistics

a = bayesian_statistics.ask(
    "Bayesian A/B test: alpha_a = 1, beta_a = 1, alpha_b = 1, beta_b = "
    "1. Probability that A beats B?"
)
print(a.outcome, a.values)
# SOLVED {'prob_a_greater': 0.5, 'prob_b_greater': 0.5}

a = bayesian_statistics.ask(
    "Find the beta prior with mean = 0.3 and standard deviation = 0.1."
)
print(a.outcome, a.values)
# SOLVED {'alpha': 6.0, 'beta': 14.0, 'prior_sample_size': 20.0}

a = bayesian_statistics.ask(
    "Law of total probability: priors = [0.5, 0.3, 0.2], conditionals "
    "= [0.01, 0.02, 0.05]. Find P(B)."
)
print(a.outcome, a.values)
# SOLVED {'p_b': 0.021, 'joint': [0.005, 0.006, 0.01]}

a = bayesian_statistics.ask(
    "KL divergence between beta distributions: alpha1 = 2, beta1 = 1, "
    "alpha2 = 1, beta2 = 1."
)
print(a.outcome, a.values)
# SOLVED {'kl': 0.19314718056}

a = bayesian_statistics.ask("Convert the probability 0.2 to odds.")
print(a.outcome, a.values)
# SOLVED {'odds': 0.25, 'odds_against': 4.0, 'log_odds': -1.38629436112}

a = bayesian_statistics.ask(
    "Equal-tailed 90% credible interval for a Beta(1, 1) posterior."
)
print(a.outcome, a.values)
# SOLVED {'lower': 0.05, 'upper': 0.95, 'median': 0.5}

a = bayesian_statistics.ask(
    "KL divergence between normal distributions: mean1 = 0, sd1 = 1, "
    "mean2 = 1, sd2 = 2."
)
print(a.outcome, a.values)
# SOLVED {'kl_1_to_2': 0.44314718056, 'kl_2_to_1': 1.30685281944}

a = bayesian_statistics.ask(
    "Monte Carlo integration with values = [1, 3]: lower = 0, upper = "
    "2."
)
print(a.outcome, a.values)
# SOLVED {'estimate': 4.0, 'standard_error': 2.0, 'n': 2}

a = bayesian_statistics.ask(
    "The pre-test probability is 0.2 and the likelihood ratio is 6. "
    "What is the post-test probability?"
)
print(a.outcome, a.values)
# SOLVED {'posterior': 0.6, 'prior_odds': 0.25, 'posterior_odds': 1.5}

a = bayesian_statistics.ask(
    "Repeated testing: prevalence 0.01, sensitivity 0.9, specificity "
    "0.95, positives = 2, negatives = 0. Posterior probability of the "
    "disease?"
)
print(a.outcome, a.values)
# SOLVED {'posterior': 0.765957446809, 'posterior_odds': 3.27272727273}

a = bayesian_statistics.ask(
    "Dirichlet-multinomial evidence for counts = [2, 1, 0] with alpha "
    "= [1, 1, 1]."
)
print(a.outcome, a.values)
# SOLVED {'probability': 0.1, 'log_probability': -2.30258509299}

a = bayesian_statistics.ask("Convert odds of 3 to a probability.")
print(a.outcome, a.values)
# SOLVED {'probability': 0.75, 'complement': 0.25}

a = bayesian_statistics.ask(
    "Mean and variance of the polynomial with coefficients = [1, 2, 3] "
    "of a normal X with mean = 0, sd = 1."
)
print(a.outcome, a.values)
# SOLVED {'mean': 4.0, 'variance': 22.0, 'sd': 4.69041575982}

a = bayesian_statistics.ask(
    "Treatment threshold with loss_fp = 1 and loss_fn = 9; the "
    "probability of disease is 0.05. Treat?"
)
print(a.outcome, a.values)
# SOLVED {'threshold': 0.1, 'decision': 'do not treat'}

a = bayesian_statistics.ask(
    "Stratified sampling: weights = [0.6, 0.4], means = [10, 20], sds "
    "= [2, 5], sizes = [30, 20]."
)
print(a.outcome, a.values)
# SOLVED {'estimate': 14.0, 'standard_error': 0.49799598392}
```

## Rust library: 15 examples

The crate `bayesian-statistics-ai999x` (in `rust/` of the GitHub repository) answers a JSON request with `bayesian_statistics_ai999x::solve_json`. Each call below was compiled and run on this release; the comment under it is what it printed. The whole program is `rust/bayesian-statistics/examples/readme.rs`: `cd rust && cargo run --release --example readme -p bayesian-statistics-ai999x`.

```rust
use serde_json::{json, Value};

fn show(request: Value) {
    let answer: Value = serde_json::from_str(&bayesian_statistics_ai999x::solve_json(&request.to_string())).unwrap();
    println!("{}", answer["outcome"].as_str().unwrap_or(""));
    for v in answer["values"].as_array().into_iter().flatten() {
        let unit = v[2].as_str().unwrap_or("");
        let unit = if unit.is_empty() || unit == "1" { String::new() } else { format!(" {unit}") };
        println!("{} = {}{}", v[0].as_str().unwrap_or(""), v[1], unit);
    }
}

show(json!({"key": "bayes_factor_normal_mean", "inputs": {"sample_mean": "0", "n": "1", "sigma": "1", "mu0": "0", "prior_sd": "1"}}));
```

## Build the program from source

`rust/` holds the Rust source of the `bayesian-statistics` command-line program and browser module: the AI999X engine (`rust/ax-engine`), this model (`rust/bayesian-statistics`) and its data (`rust/models/bayesian_statistics/pack.json`). With Rust 1.80 or later:

```bash
cd rust
cargo build --release -p bayesian-statistics-ai999x
./target/release/bayesian-statistics --help
cargo test -p bayesian-statistics-ai999x
```
